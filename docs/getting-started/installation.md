# Installation

You need two things: the rompy-xbeach Python package, which writes XBeach workspaces, and XBeach itself, which runs them.

## rompy-xbeach

rompy-xbeach needs Python 3.10 or later. It installs [rompy](https://rom-py.github.io/rompy/) and its other dependencies.

```bash
pip install rompy-xbeach
```

These docs describe the development version, which has changed a lot since the last release (0.2.0). Until the next release, install it from GitHub:

```bash
pip install "rompy-xbeach @ git+https://github.com/rom-py/rompy-xbeach.git@output"
```

### Optional extras

| Extra | Adds | Needed for |
|---|---|---|
| `extra` | [rompy-binary-datasources](https://github.com/rom-py/rompy-binary-datasources) | Using an in-memory xarray dataset as a data source ([`SourceCRSDataset`][rompy_xbeach.source.SourceCRSDataset]) |
| `docs` | [rompy-docs](https://github.com/rom-py/rompy-docs) | Building these docs |
| `dev` | pytest, ruff, coverage | Development |

```bash
pip install "rompy-xbeach[extra]"
```

## XBeach

rompy-xbeach writes the XBeach input files but does not include XBeach. There are two ways to run it.

### Docker (recommended)

The public image `ghcr.io/rom-py/xbeach` contains XBeach built with NetCDF output, in serial and MPI builds. You only need [Docker](https://docs.docker.com/get-docker/).

| Tag | Contents |
|---|---|
| `1.24.6057-halloween-beta` | The XBeach release v1.24.6057 "Halloween" (BETA) |
| `trunk-r<revision>`, e.g. `trunk-r6147` | The XBeach trunk at that SVN revision |
| `latest` | The newest `trunk-r<revision>` image |

Pin a release or trunk tag for reproducible runs, since `latest` moves when a new trunk revision is published. Every image is tested with workspaces generated by rompy-xbeach before it is published. [Running XBeach](../user-guide/running.md) shows how to use it.

### Your own XBeach

Download or build XBeach from [Deltares](https://oss.deltares.nl/web/xbeach/release-and-source) (see the [XBeach manual](https://xbeach.readthedocs.io/en/latest/xbeach_manual.html) for compilation), and make sure the `xbeach` executable is on your `PATH`. Build it with NetCDF support, since rompy-xbeach sets NetCDF output by default.

## Check the installation

```python exec="on" source="above" result="text"
import rompy
import rompy_xbeach

print(f"rompy {rompy.__version__}, rompy-xbeach {rompy_xbeach.__version__}")
```

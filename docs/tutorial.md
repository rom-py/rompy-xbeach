# Tutorial

The XBeach tutorial takes you from zero to a storm-impact setup in seven lessons. The lessons are notebooks, rendered with their outputs on the [rompy notebooks site](https://rom-py.github.io/rompy-notebooks/xbeach-tutorial/), where you can also download them. Work through them in order.

```python exec="on"
from rompy_docs.notebooks import tutorial_table

print(tutorial_table("xbeach"))
```

The notebooks and their example data are in the [rompy-notebooks](https://github.com/rom-py/rompy-notebooks/tree/main/notebooks/xbeach) repository, so they run from a clone without further setup.

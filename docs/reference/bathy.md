# Bathymetry

[`XBeachBathy`][rompy_xbeach.data.bathy.XBeachBathy] interpolates bathymetry onto the XBeach grid and writes the depth files. It builds on rompy's [`DataGrid`][rompy.core.data.DataGrid].

      show_root_heading: false
      heading_level: 3

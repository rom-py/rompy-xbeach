# Config

[`Config`][rompy_xbeach.config.Config] is the XBeach model configuration. It gathers the grid, bathymetry, forcing and model settings, and writes `params.txt` and the input files. It subclasses rompy's [`BaseConfig`][rompy.core.config.BaseConfig].

::: rompy_xbeach.config
    options:
      show_root_heading: false
      heading_level: 2
